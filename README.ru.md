Десктопное приложение, которое пытается вспомнить твою картинку так, как это
делает Комплекс из *The Backrooms* Kane Pixels («Still Life»), и почти
справляется. Картинка остаётся чёткой и узнаваемой, но её части не на своих
местах: глаза, ноздри, зубы, буквы и пятна сдвинуты, поменяны местами,
повёрнуты или забыты.

![Морская свинка в шапке-лягушке: оригинал и пять вариантов](docs/images/example-guinea-pig.jpg)

## Как это работает

1. Картинка приводится примерно к 448 px по длинной стороне.
2. **Неверное прочтение.** Цветовая сегментация находит отдельные элементы
   (небольшие контрастные области). Часть из них сдвигается, меняется местами
   с соседом, поворачивается, отражается, масштабируется, дублируется или
   пропадает. Крупные части почти не двигаются, поэтому силуэт сохраняется.
3. **Реконструкция.** SD-Turbo (img2img, 1–3 шага) перерисовывает результат,
   сглаживает швы и держит единый стиль. Самые сильные варианты делают второй
   проход: копия с копии.
4. **Якорь.** Детали оригинала возвращаются там, где ничего не двигали, а его
   грубая компоновка и цвета подмешиваются везде. Поэтому даже самый сильный
   вариант явно сделан из твоей картинки.

## Установка

Windows 10/11 и Python 3.10–3.12. При первой генерации скачиваются веса
SD-Turbo (~2,6 ГБ) в кеш Hugging Face.

```bat
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

Так работает на AMD, Intel и NVIDIA через DirectML, а также на CPU. Чтобы
использовать CUDA на NVIDIA, сначала поставь CUDA-сборку torch:

```bat
.venv\Scripts\python -m pip install torch==2.4.1 --index-url https://download.pytorch.org/whl/cu124
.venv\Scripts\python -m pip install -r requirements.txt
```

Все пакеты подобраны под `torch==2.4.1`, которую требует `torch-directml`.
Почему именно такие версии, написано в комментариях
[requirements.txt](requirements.txt).

## Использование

Запусти `run.bat` двойным кликом или:

```bat
.venv\Scripts\python main.py [--device auto|cuda|dml|cpu] [--theme light|dark]
```

1. **Open image...** или перетащи файл в окно (PNG, JPG, WEBP, BMP).
2. Выбери вариант: **Almost correct**, **Misremembered**, **Copy of a copy**,
   **Complex decay** или **Still life facsimile**.
3. **Generate**, затем **Save result**.

Устройство определяется автоматически (CUDA, затем DirectML, затем CPU) и
показано в верхней панели. Рядом кнопка **Load model / Unload model**:
загрузить SD-Turbo заранее или освободить видеопамять. Модель работает в
отдельном процессе, поэтому выгрузка действительно возвращает память. Каждый
запуск берёт новый случайный seed.

На RX 7600 генерация занимает несколько секунд. На DirectML модель занимает
около 4 ГБ видеопамяти, после первого запуска около 6 ГБ. Если памяти не
хватает, приложение пробует меньший размер, а потом переходит на CPU.

## Разработка

```bat
.venv\Scripts\python -m pip install pytest
.venv\Scripts\python -m pytest
```

Тесты проверяют кривые эффекта, загрузку изображений, каскад при нехватке
памяти, выбор устройства, окно (без дисплея) и процесс модели. Используются
крошечные случайные модели, веса не нужны.

`tools/sweep.py photo.png` рендерит все варианты рядом, чтобы подбирать кривые
в `core/misread.py` (`--no-model` пропускает SD-Turbo). Логи пишутся в
`logs/stilllife.log`.

```
main.py              точка входа
config.py            модель, служебный промпт, размеры
core/misread.py      варианты, перестановка элементов, якорь
core/pipeline.py     проходы, движок SD-Turbo, каскад по памяти
core/engine_process.py  модель в дочернем процессе, определение устройства
core/device.py       CUDA / DirectML / CPU
ui/                  окно, тема, виджеты
tools/sweep.py       сравнение вариантов
docs/images/         логотип и примеры для README
```
